# Alternative Slugterra lore source audit

Inspected 2026-11-01 (UTC): [vikhyatsingh123/SlugTerra](https://github.com/vikhyatsingh123/SlugTerra), retrieved independently through public GitHub and extracted at `.local/research/sources/vikhyatsingh123-SlugTerra/`. Read its own HTML, README and counting script; no vendor/minified code was used as lore evidence. This was research only, with no game implementation.

## Credibility and scope

The [README L3–5](https://github.com/vikhyatsingh123/SlugTerra/blob/master/README.md#L3-L5) describes a Hacktoberfest community card project and directs contributors to Fandom/Pinterest; [L14–16](https://github.com/vikhyatsingh123/SlugTerra/blob/master/README.md#L14-L16) invites anyone to add a favourite slug. It is an alternative access route, **not official canon or necessarily independent corroboration of the wiki**. Extraction confidence is high; canonical accuracy is unverified in this audit. Links use mutable `master` paths. The retrieved GitHub page reports commit `791af5973a331d159229202265dcab7ad7e6842f`; an archive-to-commit match was not independently verified.

## Slug Fu, blasters and caverns

- **Slug Fu:** Lian is called a master and Junjie's former teacher at [L4028–4033](https://github.com/vikhyatsingh123/SlugTerra/blob/master/index.html#L4028-L4033). Joker's entry names the film *Slug Fu Showdown* ([L199–201](https://github.com/vikhyatsingh123/SlugTerra/blob/master/index.html#L199-L201)). No technique list, training progression, steering/control rules or complete practitioner list was recovered.
- **Blasters:** narrative mentions only; Beeker needs no Torpedo Shell for underwater firing ([L308–311](https://github.com/vikhyatsingh123/SlugTerra/blob/master/index.html#L308-L311)). No blaster catalogue, specifications, upgrade system or ammunition capacities. Several species descriptions mention transformation at 100 mph, e.g. Bubbaleone above; no complete physics/return/capture system is specified.
- **Fusion:** Mucky/Joules in *Lightwell* ([L2691–2696](https://github.com/vikhyatsingh123/SlugTerra/blob/master/index.html#L2691-L2696)); no exhaustive compatibility model.
- **Caverns:** incidental habitat names, not a world map: **99 Caverns / Chillbore / Frozen Northern caverns** ([L1137–1142](https://github.com/vikhyatsingh123/SlugTerra/blob/master/index.html#L1137-L1142)); **Eastern Caverns** (Joo-Joo above); **Undertow** (AquaBeek above); **Cavern Sea Reef** ([L790–792](https://github.com/vikhyatsingh123/SlugTerra/blob/master/index.html#L790-L792)); **Wild Spores** (Vinedrill above); **Upright** ([L1958–1964](https://github.com/vikhyatsingh123/SlugTerra/blob/master/index.html#L1958-L1964)); **Quiet Lawn** ([L3628–3632](https://github.com/vikhyatsingh123/SlugTerra/blob/master/index.html#L3628-L3632)); **Deaddrop / Cavern of Time** ([L3105–3113](https://github.com/vikhyatsingh123/SlugTerra/blob/master/index.html#L3105-L3113)); **Lumino** ([L2707–2713](https://github.com/vikhyatsingh123/SlugTerra/blob/master/index.html#L2707-L2713)); **Deadweed** (Frightgeist above); **Deep Storage** (Boss Ember above). No connections, full registry or detailed geography was recovered. The game's Haven/Luminous Deep names are not established here.

## Exclusions and remaining gaps

- Explicit unrelated **Pokémon** entries: [Torkoal L1495–1502](https://github.com/vikhyatsingh123/SlugTerra/blob/master/index.html#L1495-L1502), [Bulbasaur L2819–2826](https://github.com/vikhyatsingh123/SlugTerra/blob/master/index.html#L2819-L2826). Exclude from Slugterra data.
- **Ghost Slug** describes a real eyeless earthworm-eating animal in centimetres ([L2426–2436](https://github.com/vikhyatsingh123/SlugTerra/blob/master/index.html#L2426-L2436)); unsupported as Slugterra lore. **Yurselfim** ([L3211–3213](https://github.com/vikhyatsingh123/SlugTerra/blob/master/index.html#L3211-L3213)), **GPO**, **Happy Slug** and **Trooper** are weakly sourced user additions, not validated species.
- Duplicates/mismatches: “Burphy,” “Frowst Crawler,” and “Engimo” spellings; “Guardian Slug” repeats Water Elemental prose ([L2895–2898](https://github.com/vikhyatsingh123/SlugTerra/blob/master/index.html#L2895-L2898)); Infurnus card uses a Tazerling filename ([L342–344](https://github.com/vikhyatsingh123/SlugTerra/blob/master/index.html#L342-L344)). Card counts are not canonical species counts.
- Rarity ambiguity: Boon Docs are “extremely rare,” while White Boon Doc prose calls its counterpart “common” ([L3301–3303](https://github.com/vikhyatsingh123/SlugTerra/blob/master/index.html#L3301-L3303)). Do not invent a reconciliation.
- Public repository/code licensing does not by itself clear franchise images for redistribution; no source images were copied into game assets in this audit.

**Coverage decision:** useful as a provisional names/relationships/habitats checklist, insufficient alone for a comprehensive faithful lore specification. Official or corroborated accessible references, or user-provided material, remain necessary for complete classification, Slug Fu, blasters and geography. Any missing mechanics must be labeled original design choices instead of attributed to canon.
